# 健身数据规范记录 Skill

## 用途

帮用户在 `/root/fitness_log.md` 中按统一格式追加健身记录，确保解析器能正确识别。

## 数据文件

- 路径：`/root/fitness_log.md`
- **只追加，不修改已有内容**
- 每次记录追加到文件末尾

## 记录格式规范

### 1. 日期标题（必须）

```
### YYYY-MM-DD（周X）
```

示例：`### 2026-07-12（周日）`

### 2. 体重记录（重要！）

**每个训练日或称重日，在日志正文中记录体重：**

```
- 体重：**63.35kg**
```

或带体脂秤数据：
```
#### ⚖️ 体测（Zepp Life）
- 体重：**63.35kg**（126.7斤）| 身体得分 90分
- BMI：24.1（偏高）| 体脂：**19.7%**（标准）| 肌肉：48.2kg（标准）
```

**格式要点**：
- 必须包含 `体重：**数字kg**`，数字和 kg 之间不要有空格
- 支持 `体重：**63.35kg**` 和 `体重：63.35kg` 两种格式
- **不需要手动更新顶部体重表**——解析器会自动从日志正文提取并合并到趋势图
- 体测其他数据（BMI/体脂/肌肉等）会被自动过滤，不会误识别为训练动作

### 3. 饮食记录（强制格式）

**⚠️ 必须严格按此格式，否则解析器无法识别。**

每行格式：
```
- 食物名 | 热量kcal | 蛋白Xg | 碳水Xg | 脂肪Xg
```

示例：
```
### 饮食
#### 早餐
- 鸡蛋 ×2 | 150kcal | 蛋白12g | 碳水1g | 脂肪10g
- 全麦面包 ×1 | 130kcal | 蛋白5g | 碳水24g | 脂肪2g
- 纯牛奶 250ml | 160kcal | 蛋白8g | 碳水12g | 脂肪8g

#### 午餐
- 鸡胸肉 120g | 200kcal | 蛋白35g | 碳水0g | 脂肪4g
- 米饭 400g | 520kcal | 蛋白10g | 碳水144g | 脂肪1g

#### 晚餐
- 土豆牛肉盖饭 | 650kcal | 蛋白35g | 碳水70g | 脂肪22g

#### 补剂
- 乳清蛋白粉 30g | 115kcal | 蛋白22g
- 一水肌酸 3g | 0kcal | 蛋白0g
```

**格式铁律**：
- 分隔符必须是 ` | `（竖线前后有空格）
- 第二列必须是 `数字kcal`（如 `150kcal`、`~140kcal`）
- 第三列必须是 `蛋白数字g`（如 `蛋白12g`）
- 第四列必须是 `碳水数字g`（如 `碳水24g`）
- 第五列必须是 `脂肪数字g`（如 `脂肪10g`）
- **不要**在数字和 kcal/g 之间加空格（写 `150kcal` 不写 `150 kcal`）
- 补剂行至少要有 `数字kcal | 蛋白数字g`
- 小计行用 `**` 包裹，不用 `|` 分隔符

### 4. 训练记录

```
### 训练
**💪 今日训练：部位**

- 动作名 | 组数信息 | 重量详情
```

示例：
```
### 训练
**💪 今日训练：腿**

- 杠铃深蹲 | 4组 | 80kg×5×4
- 俯卧腿弯举 | 4组 | 30kg×10×2 + 35kg×7×2
- 山羊挺身 | 4组 | 20kg×8×4
```

**格式要点**：
- 部位用中文：腿/胸/背/肩/手臂/腹
- 多部位用 `+`：`胸 + 三头`、`背 + 腹`
- 有氧用：`有氧：跑步` 或 `有氧：排球`
- 动作格式：`- 动作名 | X组 | 重量×次数`
- 自由格式也支持：`- 动作名 | 重量×次数` 或 `- 动作名 | 次数详情`
- 训练记录放在 `### 训练` 标题下

### 6. 修改目标体重

用户说"改目标体重到 70kg"、"目标改成 70"时，修改 fitness_log.md 顶部 `目标体重：~68kg` 行。用 sed 替换数字：

```bash
sed -i 's/目标体重：~[0-9.]*kg/目标体重：~70kg/' /root/fitness_log.md
```

改完后自动运行 python3 /root/scripts/parse_fitness.py 同步。

## 完整示例

用户说："今天练了背+腹，记一下"

你应该追加：

```
### 2026-07-12（周日）

### 训练
**💪 今日训练：背 + 腹**

- 对握下拉 | 4组 | 40kg×8×4
- 高位下拉 | 4组 | 50kg×8×4
- 悬垂举腿 | 4组 | 15次×4
```

## 关键规则

1. **不修改已有内容**：只追加，不改写
2. **日期标题必须有**：`### YYYY-MM-DD（周X）`
3. **部位用中文**：腿/胸/背/肩/手臂/腹
4. **动作分隔用 `|`**：竖线前后有空格
5. **重量中的乘号用 `×`**（不是字母 x）
6. **体测数据单独一栏**，不要混在训练或饮食里

## 数据同步

数据每 10 分钟通过服务器 crontab 自动同步。
如需立即同步，SSH 到服务器执行：
```bash
python3 /root/scripts/parse_fitness.py
```
不要依赖 Hermes 会话触发——它倾向于聊天回复而非执行命令。
